# DFT 从零开始：电脑到底在算什么，结果为什么要先检查

## 你不需要先会写计算程序

第一性原理计算文章常直接写 `DFT`、`ENCUT`、`k-point` 或 `SOC`。对第一次读的人而言，先不要背参数。先抓住一个问题：

**电脑正在比较哪些可能的材料状态，以及它的数字是否稳定到足以比较？**

DFT（density functional theory，密度泛函理论 / 密度汎関数理論）是一种用电子密度近似处理材料电子问题的计算框架。它能帮助估计能量、磁矩和电子结构，但不是把真实实验完整复制进电脑。

## 1. 输入、过程和输出

![DFT 输入输出与收敛判断教学图]({{ '/assets/dft-workflow-convergence.svg' | relative_url }})

这张图是教学流程与虚构曲线，不是某一种 Kagome 材料的真实计算结果。

**输入中最重要的几类信息：**

- 晶体结构：原子在哪里、晶格多大。结构错了，后面算得再精细也可能回答错问题。
- 元素和电子处理方式：程序需要知道怎样近似原子核附近的电子。
- 候选磁构型：例如不同自旋排列。只算一个构型，不能说它就是最低能量状态。
- 数值设置：例如平面波截断能和 k 点密度，它们决定计算是否足够精细。

**计算过程的白话版本：** 程序先猜一个电子分布，再依据这个分布求新的状态，不断更新，直到前后变化足够小。这叫 self-consistent calculation（自洽计算 / 自己無撞着計算）。

**常见输出：** 总能量、原子受力、磁矩、能带、态密度。文章需要解释哪个输出对应哪个物理结论。

## 2. 为什么必须比较候选磁构型

在 Kagome 磁性问题里，可能存在多种接近的自旋排列。计算者通常想比较两个候选状态的能量差：

\\[
\Delta E = E_{\mathrm{candidate\ A}} - E_{\mathrm{candidate\ B}}
\\]

- \\(E\\) 是某个候选状态的总能量。
- \\(\Delta E\\) 是两者差值。
- 如果 \\(\Delta E\\) 很小，那么计算精度不够时，排序可能会被数值误差反转。

因此，真正关心的不是“程序跑完了”，而是“决定结论的能量差已经稳定了吗”。

## 3. 收敛图怎样读

图中横轴表示计算越来越精细，例如逐步提高 `ENCUT` 或使用更密的 k-point mesh（k 点网格 / k点メッシュ）。纵轴表示两个候选磁状态的能量差 \\(\Delta E\\)。

- 左侧曲线乱跳：改变计算精度就改变候选排序，不能宣布谁更稳定。
- 右侧曲线趋稳：在给定检验范围内，能量差不再明显改变，才有资格继续讨论。

`ENCUT` 可以先想成“允许程序使用多细的空间波纹来描述电子”的旋钮。k 点可以先想成“在周期材料的电子空间中抽样有多密”的旋钮。它们提高通常增加成本，但不提高到足够程度，结果可能不可靠。

## 4. 数值稳定以后仍然不能跳步

**计算可以支持：**

- 在一组明确写出的假设和参数下，哪些候选状态能量更低。
- 某种电子结构特征是否在该近似下出现。
- 参数变化时结论是否稳定。

**计算单独不能证明：**

- 实验样品一定实现了计算中最低能量的理想状态。
- 缺陷、杂相、温度波动或量子涨落不重要。
- 一个没有收敛测试的漂亮能带图已经可信。

因此，材料文章应将计算与结构测量、磁性测量或谱学结果相互对照。

## 5. 第一次读 DFT 文章的检查清单

- [ ] 作者输入的晶体结构来自哪里？实验结构还是理想化模型？
- [ ] 比较了哪些磁构型，而不是只展示一个？
- [ ] `ENCUT` 与 k 点的收敛测试是否呈现，至少是否明确说明？
- [ ] 若使用 DFT+U 或 SOC，作者是否解释为什么需要以及结论是否依赖参数？
- [ ] 论文从哪个输出图或数值推到哪个结论？
- [ ] 是否与实验或已有可靠文献交叉检查？

## 6. 术语小卡片

**DFT（密度泛函理论 / 密度汎関数理論）**：以电子密度为核心变量的计算框架，用近似方法求材料的能量与电子性质。

**magnetic configuration（磁构型 / 磁気配置）**：计算开始时设置或最终得到的一种自旋排列候选。

**convergence test（收敛测试 / 収束試験）**：逐步提高数值精度，检查决定结论的输出是否稳定。

**ENCUT（平面波截断能 / 平面波カットオフエネルギー）**：控制描述电子状态所用基组精度的一个关键设置。

**k-point mesh（k 点网格 / k点メッシュ）**：周期材料电子状态取样的密度设置。

## 7. 三个练习问题

1. 如果两个磁构型只差很小能量，但文章没有给收敛检查，你会把结论标成可靠还是待核验？
2. 为什么“最低能量计算状态”不能自动等于实验样品的真实状态？
3. 在流程图中，哪一项输入如果错误，会让后续精密计算仍然回答错对象？
