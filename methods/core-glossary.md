# 核心术语随身词典：先懂词，再读论文

这个页面不是让你背诵，而是让你在读文章时不用来回搜索。每个词都按四件事解释：它是什么、为什么要用、读论文时怎么看、常见误解。

## Berry curvature

**它是什么**：Berry curvature 是能带波函数在动量空间中变化时产生的几何量。你可以先把它想成“k 空间里的有效磁场”。

**为什么要用**：它能解释某些横向输运现象，例如内禀反常霍尔电导。电子在电场中运动时，Berry curvature 可让电子速度多出一个横向分量。

**读论文时怎么看**：看它集中在哪些能带、哪些 k 区域、是否靠近 EF；再看计算得到的 AHC 是否和实验量级相容。

**常见误解**：看到 AHE 不等于已经证明 Berry curvature 是唯一来源；看到 Berry curvature 热点也不等于机制已经闭环。

## AHE / 反常霍尔效应

**它是什么**：AHE 是扣除普通 Hall 背景后仍然存在的横向电响应，常出现在磁性或时间反演对称性破缺体系中。

**为什么要用**：它是判断磁性拓扑材料中 Berry curvature、散射机制和磁结构是否重要的关键输运信号。

**读论文时怎么看**：先看作者怎样扣除普通 Hall 背景，再看 AHE 和磁化、温度、纵向电阻、样品质量是否对应。

**常见误解**：AHE 大不等于一定是拓扑；也不等于一定是 Weyl 半金属。

## Chern number / Chern 数

**它是什么**：Chern 数是二维被占据能带的整数拓扑指标，可以理解为整个能带几何“绕了几圈”的计数。

**为什么要用**：非零 Chern 数通常预示边界上会有跨过体能隙的通道，是理解量子 Hall 和量子反常 Hall 的核心指标。

**读论文时怎么看**：看体系是否有体能隙、费米能级是否在能隙中、Chern 数是哪个能带或哪个二维切片的结果。

**常见误解**：软件输出 Chern 数不等于材料已经实现量子化输运；还要看边界谱和实验。

## Edge state / 边界态

**它是什么**：边界态是出现在样品边缘或表面的电子态，和体内电子态不同。

**为什么要用**：在拓扑材料中，边界态可作为体能带拓扑的可见结果。

**读论文时怎么看**：看它是否跨过体能隙，是否连接预期的投影点，是否和普通表面态区分开。

**常见误解**：只要表面有亮线就叫拓扑边界态，这是不对的。

## Wilson loop / WCC

**它是什么**：Wilson loop 是沿 k 空间闭合路径追踪波函数相位演化的方法；WCC 是 Wannier charge center，常用来画这种演化。

**为什么要用**：它可以帮助判断 Chern 数、Z2 指标等拓扑不变量。

**读论文时怎么看**：看路径、切片、占据带数量、网格收敛，以及 WCC 曲线是否稳定穿越参考线。

**常见误解**：一张花哨的 WCC 图不自动等于拓扑非平庸；参数和收敛必须清楚。

## Quantum oscillation / 量子振荡

**它是什么**：强磁场下电子能级被量子化，电阻或磁化会随 1/B 周期性振荡。

**为什么要用**：振荡频率告诉你费米面截面积；温度衰减可给有效质量；场强衰减可给散射信息。

**读论文时怎么看**：看背景扣除、频率分析、角度依赖、温度拟合、Dingle 分析和 Landau fan 编号。

**常见误解**：频率首先说明费米面，不直接证明拓扑。

## Berry phase

**它是什么**：Berry phase 是波函数沿闭合路径变化后累积的几何相位。

**为什么要用**：在量子振荡中，它可能提示电子轨道是否包围 Dirac 或 Weyl 型能带奇点。

**读论文时怎么看**：看 Landau fan 编号、相位截距、维度修正、Zeeman 效应和多频率影响。

**常见误解**：相位接近某个数值不等于单独证明拓扑，尤其在三维金属中要谨慎。

## Weyl point / Weyl 点

**它是什么**：Weyl 点是三维动量空间中两个非简并能带的线性交叉点，带有正或负手性。

**为什么要用**：Weyl 点像 Berry curvature 的源或汇，可带来 Fermi arc、异常霍尔响应等现象。

**读论文时怎么看**：看 Weyl 点位置、能量、手性、是否成对出现、离 EF 多远。

**常见误解**：找到 Weyl 点不等于实验一定能看到 Fermi arc。

## Fermi arc

**它是什么**：Fermi arc 是 Weyl 半金属表面上可能出现的开放弧形表面态。

**为什么要用**：它是 Weyl 半金属表面电子结构的标志性线索。

**读论文时怎么看**：看它是否连接相反手性的 Weyl 点投影，是否与体态投影和普通表面态区分。

**常见误解**：表面谱上一条亮线不一定是 Fermi arc。

## ARPES

**它是什么**：ARPES 是角分辨光电子能谱，用光把电子打出样品，再测电子能量和角度来重建能带。

**为什么要用**：它能直接看到能量-动量关系，是读 Dirac 点、能隙、表面态的重要实验工具。

**读论文时怎么看**：看测的是哪个表面、哪个能量窗口、谱线是否清楚、是否和 DFT 对上。

**常见误解**：ARPES 看到一条亮带不等于整个三维体能带都已经确定。

## DFT / Wannierization

**它是什么**：DFT 是第一性原理电子结构计算；Wannierization 是把 DFT 能带转成局域轨道模型，便于高密度插值和拓扑计算。

**为什么要用**：很多 Berry curvature、AHC、Wilson loop、Weyl 点和表面谱计算都需要可靠的 Wannier 模型。

**读论文时怎么看**：先看 Wannier 能带是否复现 DFT，尤其是 EF 附近和目标能隙附近。

**常见误解**：只要软件能跑出图，就代表模型可信，这是不对的。
