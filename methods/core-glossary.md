# 核心术语随身词典：先懂词，再读论文

这个页面不是让你背诵，而是让你读文章时不用来回搜索。每个词都按四件事解释：它是什么，为什么要用，读论文时怎么看，常见误解是什么。

## Berry curvature

**它是什么**：先不要把 Berry curvature 当公式背。把能带想成一张电子运动地图：每个点代表电子在晶体里一种可能的运动状态。Berry curvature 就是这张地图上每个点附带的“侧向偏移规则”。

**为什么要用**：当电场推动电子时，某些能带区域会让电子多出一个向侧面的运动趋势，于是材料可能出现反常 Hall 电流。它帮助我们判断横向电流是否可能来自材料自身的能带结构。

**读论文时怎么看**：看强 Berry curvature 是否靠近费米能级；它来自哪两条能带、哪个小能隙或哪个交叉附近；作者算出的 AHC 是否和实验同号、同量级。

**常见误解**：它不是真实磁场；看到 Berry curvature 热点也不等于已经证明实验 AHE 只来自内禀机制，还要检查普通 Hall 背景扣除、散射贡献、磁化对应关系和样品质量。

## AHE / 反常霍尔效应

**它是什么**：AHE 是扣除普通 Hall 背景后仍然存在的横向电压或横向电导，常出现在磁性或时间反演对称性破缺的体系中。

**为什么要用**：它是判断磁性拓扑材料中 Berry curvature、散射机制和磁结构是否重要的关键输运信号。

**读论文时怎么看**：先看作者怎样扣除普通 Hall 背景，再看 AHE 和磁化、温度、纵向电阻、样品质量是否对应。

**常见误解**：AHE 大不等于一定是拓扑；也不等于一定是 Weyl 半金属。

## Chern number / Chern 数

**它是什么**：Chern 数是描述一组二维能带整体拓扑性质的整数。粗略说，它给这组能带的整体“绕法”计数。

**为什么要用**：非零 Chern 数通常预示边界上会有跨过体能隙的导电通道，是理解量子 Hall 和量子反常 Hall 的核心指标。

**读论文时怎么看**：看体系是否有体能隙、费米能级是否在能隙中、Chern 数对应的是哪组能带或哪个二维切片。

**常见误解**：软件输出 Chern 数不等于材料已经实现量子化输运；还要看边界谱和实验。

## Edge state / 边界态

**它是什么**：边界态是出现在样品边缘或表面的电子态，和体内电子态不同。

**为什么要用**：在拓扑材料中，边界态可作为体能带拓扑的可见结果。

**读论文时怎么看**：看它是否跨过体能隙，是否连接预期的投影点，是否和普通表面态区分开。

**常见误解**：表面有亮线不一定就是拓扑边界态。

## Wilson loop / WCC

**它是什么**：Wilson loop 是沿 k 空间路径追踪波函数相位变化的方法；WCC 是 Wannier charge center，常用来画这种变化。

**为什么要用**：它可以帮助判断 Chern 数、Z2 指标等拓扑不变量。

**读论文时怎么看**：看路径、切片、占据带数量、网格收敛，以及 WCC 曲线是否稳定穿越参考线。

**常见误解**：一张漂亮 WCC 图不自动等于拓扑非平庸；参数和收敛必须清楚。

## Quantum oscillation / 量子振荡

**它是什么**：强磁场下电子能级被重新分成一层层离散能级，电阻或磁化会随磁场出现周期性振荡。

**为什么要用**：振荡频率告诉你费米面截面面积；温度衰减可给有效质量；场强衰减可给散射信息。

**读论文时怎么看**：看背景扣除、频率分析、角度依赖、温度拟合、Dingle 分析和 Landau fan 编号。

**常见误解**：振荡频率首先说明费米面，不直接证明拓扑。

## Berry phase

**它是什么**：Berry phase 是电子状态沿闭合路径变化一圈后积累的额外相位。

**为什么要用**：在量子振荡中，它可能提示电子轨道是否包围 Dirac 或 Weyl 型能带奇点。

**读论文时怎么看**：看 Landau fan 编号、相位截距、维度修正、Zeeman 效应和多频率影响。

**常见误解**：相位接近某个数值不等于单独证明拓扑，尤其在三维金属中要谨慎。

## Weyl point / Weyl 点

**它是什么**：Weyl 点是三维 k 空间中两条非简并能带的线性交叉点，带有正或负手性。

**为什么要用**：Weyl 点像 Berry curvature 的源或汇，可带来 Fermi arc、异常 Hall 响应等现象。

**读论文时怎么看**：看 Weyl 点位置、能量、手性、是否成对出现、离费米能级多远。

**常见误解**：找到 Weyl 点不等于实验一定能看到 Fermi arc。

## Fermi arc

**它是什么**：Fermi arc 是 Weyl 半金属表面上可能出现的开放弧形表面态。

**为什么要用**：它是 Weyl 半金属表面电子结构的标志性线索。

**读论文时怎么看**：看它是否连接相反手性的 Weyl 点投影，是否与体态投影和普通表面态区分。

**常见误解**：表面谱上一条亮线不一定是 Fermi arc。

## ARPES

**它是什么**：ARPES 是角分辨光电子能谱，用光把电子打出样品，再测电子能量和角度来重建能带。

**为什么要用**：它能直接看到能量-动量关系，是读 Dirac 点、能隙、表面态的重要实验工具。

**读论文时怎么看**：看测的是哪个表面、哪个能量窗口、谱线是否清楚、是否和 DFT 对上。

**常见误解**：ARPES 看到一条亮带不等于整个三维体能带都已经确定。

## DFT / Wannierization

**它是什么**：DFT 是第一性原理电子结构计算；Wannierization 是把 DFT 能带转成局域轨道模型，便于高密度插值和拓扑计算。

**为什么要用**：很多 Berry curvature、AHC、Wilson loop、Weyl 点和表面谱计算都需要可靠的 Wannier 模型。

**读论文时怎么看**：先看 Wannier 能带是否复现 DFT，尤其是费米能级附近和目标能隙附近。

**常见误解**：软件能跑出图不等于模型可信。

## μSR

**它是什么**：μSR 是把自旋极化的正缪子打进样品，观察缪子自旋怎样随时间变化，从而感知局域磁场。

**为什么要用**：它能检查样品内部是否有静态磁序、磁涨落或体积分数问题。

**读论文时怎么看**：看温度依赖、弛豫率、振荡信号、是否全体积进入某个磁状态。

**常见误解**：μSR 看到局域磁场不等于已经知道具体磁结构；具体排列常需要中子散射等补充。

## Neutron scattering / 中子散射

**它是什么**：中子散射是用中子打到样品上，根据中子能量和方向的改变来读取原子位置或磁矩排列。

**为什么要用**：它能直接给出磁结构、磁激发、晶格结构，是判断磁有序的重要实验。

**读论文时怎么看**：看散射峰出现在哪里、随温度如何变化、作者拟合出的磁结构是否唯一。

**常见误解**：看到一个峰不等于磁结构已经完全确定；还要看系统消光、畴、仪器分辨和模型比较。
